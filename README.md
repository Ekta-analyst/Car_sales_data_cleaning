# Car Sales Data Cleaning Project 🚗

A comprehensive data portfolio project demonstrating advanced data cleaning and validation techniques using SQL (Google BigQuery) to ensure data integrity and accurate vehicle inventory analysis.

## 📌 Project Overview
- *Objective:* Clean, standardize, and validate car sales data to prevent flawed business insights, incorrect vehicle reporting, and misinformed stakeholder decisions.
- *Tools Used:* SQL / Google BigQuery.

## 🛠️ Key Tasks & SQL Techniques Performed
1. *Task 1: Value Consistency Check* – Used DISTINCT queries to confirm that columns like fuel_type do not contain any unexpected or anomalous values
2. *Task 2: Length Validation* – Checked the minimum and maximum string lengths in the database to identify formatting anomalies.
3. *Task 3 & 4: Handling Null & Missing Values* – Identified missing data points using IS NULL checks and established logical strategies to handle and fill those missing values.
4. *Task 5: Data Correction & Updates* – Utilized UPDATE statements to rectify potential errors, fix misspellings across rows, and standardize data formats.
5. *Task 6 : Advanced Cleaning Functions:*
   - Applied *TRIM* functions to remove unwanted spaces.
   - Used conditional length statements (LENGTH) to analyze string variable sizes.
   - Performed data removal and consistency checks (such as validating drive columns) to maintain clean records.
6. *Task 7 : Data deletion* - used deleting queries to remove unwanted rows.
